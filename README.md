# 🧠 Algoritmos de Programação — C

Repositório com exercícios e atividades desenvolvidos durante a disciplina de **Algoritmos de Programação**, do curso de **Análise e Desenvolvimento de Sistemas da Universidade Positivo**.

Ao longo da disciplina, os conteúdos evoluem dos fundamentos da **linguagem C e lógica de programação** até a utilização de estruturas de decisão, repetição, vetores, matrizes, strings, structs e funções para resolução de problemas computacionais.

---

## 📚 Sobre o repositório

O repositório registra a evolução prática dos conteúdos estudados durante a disciplina através de diferentes exercícios desenvolvidos em **C**.

As primeiras atividades trabalham operações matemáticas e estruturas condicionais. Conforme o conteúdo avança, são introduzidos laços de repetição, vetores, matrizes e manipulação de strings.

Nas atividades finais são utilizados também **structs e funções**, aplicando conceitos de organização e modularização do código.

# ▶️ Como executar

Os exercícios são programas independentes escritos em C.

## Pré-requisitos

Para execução local:

* Compilador C, como **GCC**
* Terminal ou IDE com suporte à linguagem C

Clone o repositório:

```bash
git clone https://github.com/GabrielDittrich/c-algoritmo-de-programacao.git
```

Entre na pasta:

```bash
cd c-algoritmo-de-programacao
```

Escolha o exercício que deseja executar.

Por exemplo:

```bash
cd Aula13
```

Compile utilizando GCC:

```bash
gcc mediaVetor.c -o mediaVetor
```

Execute:

### Linux/macOS

```bash
./mediaVetor
```

### Windows

```bash
mediaVetor.exe
```

---

## 🌐 Execução online

Por serem programas independentes em C, os códigos também podem ser testados utilizando compiladores C online.

Basta copiar o conteúdo do arquivo `.c` desejado para uma ferramenta compatível e executar o programa.
